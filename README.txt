KRISHNAVENI PORTFOLIO

Files:
- index.html
- style.css
- script.js
- assets/profile.jpg
- assets/Krishnaveni_Resume.pdf

HOW TO RUN:
1. Open this folder in VS Code.
2. Install the Live Server extension (optional).
3. Right-click index.html -> Open with Live Server.
   OR simply double-click index.html.

HOW TO CHANGE PROFILE PHOTO:
- Replace assets/profile.jpg with your original photo.
- Keep the same filename: profile.jpg
- Recommended portrait image size: at least 800 x 1000 px.
- CSS displays it inside a 310 x 390 px frame on desktop using object-fit: cover.
